# Awesome Solid 

A curated list of Free and Open Source Software (FOSS) resources for the Solid ecosystem, extracted from a larger dataset.

## Pod Servers

Open-source software for hosting your own Solid Pod.

* **[Community Solid Server (CSS)](https://communitysolidserver.github.io/CommunitySolidServer/latest/)** - A modular, extensible, and standards-compliant Solid server. [[Repository](https://github.com/CommunitySolidServer/CommunitySolidServer/)]
* **[Node Solid Server (NSS)](https://github.com/nodeSolidServer/node-solid-server)** - The original Solid server implementation.
* **[Pivot](https://github.com/solid-lite/server)** - A community-maintained fork of CSS.

## Public Pod Instances

Publicly available Solid Pod hosting services powered by open-source servers and provided by FOSS-aligned entities.

* **[solidweb.org](https://solidweb.org)** - A public Solid server based in Germany, powered by NSS.
* **[solidweb.me](https://solidweb.me)** - A public Solid server powered by CSS.
* **[Pod.LiquidSurf](https://pod.liquid.surf/)** - Public Solid server powered by CSS.
* **[teamid.live](https://teamid.live)** - Public Solid server powered by Pivot.
* **[Data Pod (igrant.io)](https://datapod.igrant.io/)** - Public Solid server powered by NSS.
* **[Solid Community AU](https://pods.solidcommunity.au/)** - Public Solid server powered by CSS.
* **[Mastopod](https://mastopod.com/)** - Solid server powered by ActivityPods.

## Applications & Platforms

Open-source applications and platforms built on Solid.

* **[Easy Penny](https://github.com/liquid-surf/easy-penny)** - A Pod App / Frontend.
* **[Sleepy Bike Platform](https://github.com/OpenHospitalityNetwork/sleepy.bike)** - A decentralized hospitality exchange community platform ('Couchsurfing' for bicycle travellers). (Status: Development)
* **[PASS](https://github.com/codeforpdx/PASS)** - An open source digital wallet for providing home-insecure individuals a safe place to store documents within their control, powered by CSS. (Status: Development)

## Specialized Services

Solid-powered services focused on specific domains, provided by FOSS-aligned entities.

* **[Solid Health (AU)](https://sii.anu.edu.au/projects.html)** - A service for members of the Yarrabah Aboriginal Community to store private health data.
* **[Welcome to My Place](https://mastopod.com/)** - Private meetings at home that promote welcome, trust and mutual aid, powered by ActivityPods.
* **[Mutual Aid](https://mutual-aid.app/)** - Classified ads to support each other within a trusted network, powered by ActivityPods.
* **[sleepy.bike](https://sleepy.bike/)** - A decentralized hospitality exchange community for slow travellers, powered by CSS.
